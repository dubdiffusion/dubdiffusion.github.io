SEO Reports Tool

SEO Reports Tool is a private application for preparing SEO reports. It reads Google Search Console data for the sites that the signed-in account can already access.

What it does

  • Lists the Search Console properties available to the signed-in account.
  • Reads clicks, impressions, click-through rate and average position.
  • Reads sitemap and URL index status information.

Read-only access

The application requests read-only access to Search Console. It cannot change settings, sites or data.

Who uses it

This is not a public service. The application is used only by its operator.
