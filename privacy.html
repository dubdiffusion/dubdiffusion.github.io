Privacy Policy

SEO Reports Tool. Last updated: November 4, 2026.

Data the application accesses

With the account holder's consent, the application uses the Google scope webmasters.readonly to read:

  • the list of Search Console properties available to the account;
  • search performance data: queries, pages, clicks, impressions, click-through rate and position;
  • sitemap and URL index status information.

The application does not request access to email, contacts, calendar or files.

How the data is used

The data is used only to prepare SEO reports and analysis for the sites concerned.

Storage

Sign-in tokens are stored on the operator's own computer. The application has no server of its own. Reports are kept in the operator's own files and accounts.

Sharing

The data is not sold and is not used for advertising. Reports are shared only with the people responsible for the site concerned. The operator may use an AI assistant, Claude by Anthropic, to process the data when preparing analysis.

Revoking access

Access can be removed at any time in your Google Account permissions.
